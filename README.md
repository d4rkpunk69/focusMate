# ⏱️ FocusMate - Pomodoro Timer App

**FocusMate** is a minimalist and effective Pomodoro timer app built with **Kotlin** to help you stay productive and focused. It follows the classic Pomodoro technique—25 minutes of focused work followed by short breaks—to boost efficiency and prevent burnout.

---

## 📱 Features

- ✅ Clean and intuitive UI for distraction-free focus
- ⏰ Customizable Pomodoro timers and Break timers
- 🔔 Notification alerts and sound cues
- 📊 Basic session tracking (Pomodoros completed)
- 🌙 Light and Dark themes
- 💤 Auto-start next session option (toggleable)
